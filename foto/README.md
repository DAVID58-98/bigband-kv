# Fotogalerie

Soubory `foto_1.webp` … `foto_19.webp` — pás v sekci Galerie.
Šířka 660 px (330 CSS px @2x), na šířku, WebP, kvalita ~82.
Web zobrazuje prvních deset, zbytek je v záloze.

`kapelnik.webp` — fotka kapelníka Zdeňka Kráma vedle textu „Čtyřicet let
swingu". Na výšku, minimálně 620 × 820 px. Ořezává se do oblouku, takže
**nahoře nech volný prostor** — horní část se zaoblí.
Dokud soubor chybí, ukáže se ozdobný rám s monogramem ZK.

Stáhne a převede: `bash skripty/stahnout-media.sh`
