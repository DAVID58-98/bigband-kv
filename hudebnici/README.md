# Portréty hudebníků

Web očekává **PNG s průhledným pozadím**: `<jmeno>.png`

- rozměr 660 × 880 px (poměr 3:4)
- postava zarovnaná k **dolní hraně** (dlaždice ji „posadí" na spodek oblouku)
- nahoře nech vzduch, horní hrana dlaždice je zaoblená
- jednotné světlo a jednotný ořez po hrudník — ve světlém layoutu se
  nesourodý snímek okamžitě pozná

Očekávané názvy souborů najdeš v `data/hudebnici.json` v poli `soubor`.

Dokud fotka chybí, dlaždice ukáže monogram hudebníka — nic se nerozbije,
web zůstane funkční.
