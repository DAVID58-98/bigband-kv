# Favicony

**Hotovo.** Zlatá trumpeta na tmavém kolečku se zlatým kroužkem — čitelná
ve světlém i tmavém režimu prohlížeče (původní černá trumpeta v tmavém
režimu mizela).

Zdroj: `trumpet.ico` od Davida, přebarveno na `#E8D6A8`, podklad `#16161A`.

Soubory: `favicon.ico` (multi-size), `favicon-16/32/48/96/128/180/192/256/512.png`,
`apple-touch-icon.png`.

`trumpeta-maska.png` — silueta trumpety pro CSS masku. Používá ji logo
v navigaci a odznáček cookie lišty, takže se barví podle kontextu
(zlatá `#8C6A16` na světlém, `#E8D6A8` na tmavém). Needituj bez náhrady.
